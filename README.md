# My PWA App with React + TypeScript + Vite

In this project, I've used the following technologies:

React for building the user interface.
TypeScript for type safety and better developer experience.
Vite for fast build and development.
Tailwind CSS for utility-first styling.
React Router for client-side routing and navigation.
React Query for data fetching, caching, and state management.
Leaflet for displaying interactive maps and markers.
For the server, json-server is used to mock a REST API. It watches the db.json file for changes and runs on port 3001.

A Dockerfile is included for easy deployment of the application.
GitLab CI or GitHub Actions can be used for continuous integration and automation.
A deployment YAML file for Kubernetes is provided to deploy the app in a Kubernetes environment.
